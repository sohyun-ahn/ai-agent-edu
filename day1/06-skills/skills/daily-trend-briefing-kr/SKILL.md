# 매일 트렌드 브리핑

## 사용 시기
- 대한민국 기준으로 주말, 공휴일, 대체공휴일이 아닌 날에 아침 7시 브리핑이 필요할 때 사용한다.
- 사용자가 “오늘 트렌드 알려줘”, “아침 브리핑 만들어줘”처럼 매일의 최신 흐름 요약을 요청할 때 사용한다.
- 정치, 경제, 사회, 연예, fortune teller 5개 주제를 함께 보고 싶을 때 사용한다.

## 절차
### 1단계. 오늘이 브리핑 대상인지 확인한다.
- 대한민국 기준으로 주말, 공휴일, 대체공휴일인지 확인한다.
- 대상이 아니면 브리핑을 생성하지 않고 예외 처리 규칙에 따른다.
- 대상일 때만 다음 단계로 진행한다.

### 2단계. 5개 주제의 트렌드를 수집한다.
- 정치, 경제, 사회, 연예, fortune teller를 각각 확인한다.
- 각 주제마다 최신성과 의미가 있는 흐름을 우선한다.
- 경제는 시장, 산업, 정책, 투자 해석에 도움이 되는 흐름을 함께 본다.
- 정치, 경제, 사회, 연예는 서로 상반된 관점이나 보도 차이가 있으면 함께 확인한다.

### 3단계. 각 주제별 핵심 트렌드를 선정한다.
- 각 주제당 2개 정도의 트렌드를 고른다.
- 이슈가 부족하면 반드시 2개를 억지로 채우기보다 관련성이 높은 항목으로 보강하거나, 부족함을 드러내는 방향으로 정리한다.
- fortune teller는 사용자 생년월일 1998년 7월 25일을 기준으로 사주와 별자리를 종합해 오늘의 흐름과 주의점을 도출한다.
- fortune teller는 단정적이고 유머러스한 톤으로 쓴다.

### 4단계. 각 항목의 핵심 내용을 작성한다.
- 각 트렌드는 다음 요소를 포함해 정리한다.
  - 제목
  - 2~3문장 요약
  - 왜 중요한지
- 한 주제당 전체적으로 약 5문장 정도의 분량을 유지한다.
- 경제 항목의 “왜 중요한지”에는 주식, 산업, 정책 영향으로 이어질 수 있는 해석을 포함할 수 있다.
- 단, 특정 종목 추천처럼 단정적으로 확정하지 말고 흐름과 연결 포인트 중심으로 쓴다.

### 5단계. 출력 구성을 정리한다.
- 정치 → 경제 → 사회 → 연예 → fortune teller 순서로 정리한다.
- 각 주제는 구분이 명확하게 보이도록 항목별로 나눈다.
- Notion처럼 읽기 쉽게 이모지를 활용한다.
- 전체 분량은 1페이지 내외로 간결하게 유지한다.

## 출력 형식
- 뉴스레터 톤으로 작성한다.
- 항목별로 구분해서 보여준다.
- 각 주제는 아래 요소를 포함한다.
  - 이모지와 함께 주제명
  - 트렌드 제목
  - 2~3문장 요약
  - 왜 중요한지
- 예시 구조:
  - 🏛️ 정치
    - 제목
    - 요약
    - 왜 중요한지
  - 💹 경제
    - 제목
    - 요약
    - 왜 중요한지
- 문장은 너무 딱딱하지 않게, 읽기 편한 뉴스레터형 문체를 사용한다.
- fortune teller는 오늘의 흐름과 주의점을 중심으로, 단정적이면서도 유머가 느껴지는 표현을 사용한다.

## 예외 처리
- 주말, 공휴일, 대체공휴일이면 브리핑 생성을 중단한다.
- 해당 날짜에 이슈가 부족하면 억지로 채우지 말고 가장 관련성 높은 항목 위주로 정리하거나 부족함을 자연스럽게 반영한다.
- 정치, 경제, 사회, 연예의 상반된 보도가 있을 경우, 한쪽만 선택하지 말고 관점을 함께 병기한다.
- fortune teller에 필요한 정보가 부족할 때는 기본값으로 사용자 생년월일 1998년 7월 25일을 사용한다.
- 공휴일 판정이 애매하면 대한민국 기준의 공식 휴일 여부를 우선 확인한다.
- 출력 분량이 과도하게 길어지면 우선순위가 높은 흐름부터 남기고 나머지는 압축한다.
